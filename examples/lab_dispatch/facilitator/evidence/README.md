# 검증 범위 · 2026-11-04

- `python3 examples/lab_dispatch/verify.py`: 기본 입력/실현 가능 계획, 부분 기간, 집중 요청 계획, 부정 대조 19건 통과. 실제 출력은 checks.json.
- Python 구문 검사: generate.py, verify.py, launch.py 통과. 웹 제품 코드는 만들지 않았으므로 제품 빌드는 해당하지 않음.
- 로컬 콘솔 실제 API: 참가자 원문 9개 등록, 참가자 파일 목록에 정책/witness 없음, 담당자 첫 인사 수신 및 턴 종료, 정상 --resume 후 원문/인사 중복 없음 확인.
- 새 Codex 세션에서 읽기 전용 독립 리뷰: independent-review.txt. 개인 CLI 설정의 모델 버전 충돌로 첫 시도 실패 후 사용자 설정을 변경하지 않는 --ignore-user-config로 실행. 기본 모델 이름은 지정하지 않음.
- 비차단 한계: 원격 생성 성공과 로컬 상태 저장 사이에 강제 중단되면 resume이 evidence를 중복 등록할 수 있음. 장애 주입은 미실행. 검토 결과를 무결함 보증으로 해석하지 않음.
- 담당자의 첫 인사 이후 장시간 대화 일관성, 실제 브라우저 클릭, 참가자가 앞으로 만들 제품의 기능·DB·인증·내보내기는 미검증. 폴더 분리는 보안 격리가 아님.

담당자 프로젝트에는 정책과 역할만 복사하며 이 증거와 정답 계획은 복사하지 않는다. 참가자용 자동 채점 결과가 아니다.

## 프로젝트 구분 수정 · 2026-11-04

사용자 지적에 따라 프로젝트를 LINKLAB 하나로 통합했다. 담당자 대화는 같은 프로젝트로 이동하고 초기화 실행 기록은 보관했다. 위 초기 독립 리뷰는 통합 전 버전에 해당한다. 이번 수정은 Store 검사 13건, 타입 검사·빌드, launcher의 통합/재개 검사와 실제 브라우저에서 LINKLAB 아래 담당자 대화를 확인했다. 원문 근거 9개와 기존 대화를 보존했다.
