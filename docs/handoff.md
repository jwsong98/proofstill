# 한 폴더로 인계하기

저장소 루트에서 실행합니다. 웹 서버나 모델을 실행할 필요가 없습니다.

```sh
npm --prefix console run handoff
```

`handoff/<생성시각>/README.md`부터 읽습니다. 다른 프로젝트는 `-- --root /path/to/project`, 출력 위치는 `-- --output /새/인계폴더`, 콘솔 DB는 `-- --db /path/to/console.sqlite`로 지정합니다. 출력 위치는 새 폴더여야 하며 기존 폴더를 덮어쓰지 않습니다. Node 24 이상과 설치된 console 의존성이 필요합니다.

| 파일 | 내용 |
|---|---|
| README.md | 기준 커밋·미커밋 여부·전체 수·누락·문서 목록 |
| implemented.md | 구현 완료로 기록된 항목 |
| verified.md | 현재 구현·검사·기준·독립 리뷰·전체 게이트가 확인된 항목 |
| unverified.md | 미실행·실패·중단·재검증 필요·남은 구현·결정 대기 |
| details.md | 모든 요구의 원문·코드 위치·검사 명령·실제 출력·리뷰·한계·다음 행동 |
| snapshot.json | 위 문서의 원본 데이터 |
| documents/ | Git에 등록된 기존 Markdown 문서(vendor·템플릿 제외) |

구현 완료여도 미검증일 수 있으므로 두 목록에 함께 나타날 수 있습니다. 이전 작업도 빠짐없이 포함하고 표시합니다. 등록되지 않은 기능을 자동 추측하지 않으며, 미추적 문서는 수집하지 않습니다. 콘솔 DB가 없거나 해당 프로젝트가 없으면 하네스 기록만 포함하고 누락을 명시합니다. 일부 조회 실패 또는 등록 항목 없음은 문서를 남기고 종료 코드 2를 반환합니다.

이 명령은 기존 상태를 조회해 문서화합니다. 검사·모델·독립 리뷰를 재실행하거나 소스를 임시 폴더에 복사하지 않습니다. 문서는 인계용 산출물이고 코드·DB 복원 패키지는 아닙니다. 실제 검증 범위, 생략된 출력과 원본 로그 위치를 확인하고 코드는 기록된 Git 커밋으로 받습니다. 미커밋 변경이 있으면 커밋에 고정된 근거로 취급하지 않습니다. 사용자 수용은 별도입니다.
